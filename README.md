# アレフベート — iPadで学ぶヘブライ語

iPadのSafariで動くヘブライ語学習アプリ（PWA）です。ホーム画面に追加するとアプリとして全画面で使え、オフラインでも動きます。

## 機能

| 機能 | 内容 |
|---|---|
| 今日のレッスン | 毎日自動で組まれるおすすめレッスン（復習 → 文字 → 新しい単語 → 確認クイズ）。途中でやめても続きから再開 |
| 記録 | 学習時間・連続日数・カレンダー・直近7日のグラフ・文字/単語の習熟度・苦手なものを自動で記録して表示 |
| アレフベート | 22文字＋語末形5文字。名前・音・例の単語を音声つきで表示 |
| 単語カード | 基本63語（10カテゴリ）。間隔反復（1日→2日→4日…）で復習 |
| クイズ | 文字→名前／名前→文字／単語→意味／意味→単語／聞き取り の5モード、各10問 |
| 書き取り | Apple Pencil（または指）でお手本をなぞり、形の重なりで自動採点。筆圧対応、Pencilのみモードあり |

学習記録はiPadの中（localStorage）だけに保存されます。Safariの「履歴とWebサイトデータを消去」で消えます。

### 今日のレッスンの決まり方（`js/lesson.js`）

1. **復習**：今日が復習日の単語（最大20枚）
2. **文字**：まだ「定着」していない文字を順に3つ（説明 → 書き取り）。全部定着したら書き取りの点が低い文字を練習
3. **新しい単語**：まだ学んでいない単語を5つ。覚えた文字だけで読める単語を優先
4. **確認クイズ**：今日の文字・単語と、クイズで間違えたものから10問

文字は「書き取り70点以上」と「クイズで2回以上正解」の両方を満たすと定着です。学習時間は、画面を表示して操作している間だけ数えます。

## iPadで使う

1. このフォルダをHTTPSで公開する（下記のGitHub Pagesが簡単です）
2. iPadのSafariでURLを開く
3. 共有ボタン →「ホーム画面に追加」

**発音が聞こえない場合**：iPadの「設定 → アクセシビリティ → リーダーと読み上げ → 声 → ヘブライ語」で音声をダウンロードしてください。

### GitHub Pagesで公開する

リポジトリの Settings → Pages → Source を「Deploy from a branch」にして、公開したいブランチと `/ (root)` を選びます。数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

## 手元で動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

ビルドは不要です（素のHTML/CSS/JavaScript）。

## 構成

```
index.html            画面の枠とタブバー
css/style.css         見た目（ライト／ダーク対応）
js/app.js             画面の切り替えと各学習モード
js/data.js            文字・単語データ（単語を増やすときはここ）
js/store.js           進捗・学習記録の保存と間隔反復
js/lesson.js          今日のレッスンの組み立てと習熟度の判定
js/speech.js          ヘブライ語の読み上げ
js/writing.js         書き取りパッドと採点
sw.js                 オフライン用キャッシュ
manifest.webmanifest  ホーム画面アプリの設定
```

オンライン時は常に最新のファイルを取りに行き、オフライン時だけ保存済みのファイルを使います（`sw.js`）。
