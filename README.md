# アレフベート — iPadで学ぶヘブライ語

iPadのSafariで動くヘブライ語学習アプリ（PWA）です。ホーム画面に追加するとアプリとして全画面で使え、オフラインでも動きます。

## 機能

| 機能 | 内容 |
|---|---|
| アレフベート | 22文字＋語末形5文字。名前・音・例の単語を音声つきで表示 |
| 単語カード | 基本63語（10カテゴリ）。間隔反復（1日→2日→4日…）で復習 |
| クイズ | 文字→名前／名前→文字／単語→意味／意味→単語／聞き取り の5モード、各10問 |
| 書き取り | Apple Pencil（または指）でお手本をなぞり、形の重なりで自動採点。筆圧対応、Pencilのみモードあり |

学習記録はiPadの中（localStorage）だけに保存されます。

## iPadで使う

1. このフォルダをHTTPSで公開する（下記のGitHub Pagesが簡単です）
2. iPadのSafariでURLを開く
3. 共有ボタン →「ホーム画面に追加」

**発音が聞こえない場合**：iPadの「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → ヘブライ語」で音声をダウンロードしてください。

### GitHub Pagesで公開する

リポジトリの Settings → Pages → Source を「Deploy from a branch」にして、公開したいブランチと `/ (root)` を選びます。数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

## 手元で動かす

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

ビルドは不要です（素のHTML/CSS/JavaScript）。

## 構成

```
index.html            画面の枠とタブバー
css/style.css         見た目（ライト／ダーク対応）
js/app.js             画面の切り替えと各学習モード
js/data.js            文字・単語データ（単語を増やすときはここ）
js/store.js           進捗の保存と間隔反復
js/speech.js          ヘブライ語の読み上げ
js/writing.js         書き取りパッドと採点
sw.js                 オフライン用キャッシュ
manifest.webmanifest  ホーム画面アプリの設定
```

**ファイルを更新したら `sw.js` の `VERSION` を上げてください。** 上げないと、iPadに古い版がキャッシュされたまま残ります。
